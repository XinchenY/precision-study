# MHD 精度分析 (fp32 vs fp64) — 结果梳理

> 目的:量化单精度(fp32)相对双精度(fp64)在理想 MHD 求解器上的表现,
> 为后续"混合精度提速"与 MCA 有效位数分析建立确定性基准。
> 求解器:MUSCL-Hancock + HLL/HLLD (+ 2D 用 GLM 散度清理),`-O2` 无 `-march`(跨机逐位一致)。
> 误差范数定义见 `analysis/mhd/compare_precision.py`;`relL2 = L2/RMS(fp64)`,
> 且 **relL2 ≈ 10^(−有效位数)**(例:relL2=1e-6 ⟺ ~6 位有效数字)。

---

## 1. 1D Brio-Wu 激波管

### 1.1 测试设置
- 理想 MHD Brio-Wu shock tube,`γ = 2`,`x ∈ [0,1]`,间断在 `x = 0.5`,`t_end = 0.1`,CFL = 0.4
- 左:`ρ=1, p=1, v=0, Bx=0.75, By= 1`  右:`ρ=0.125, p=0.1, v=0, Bx=0.75, By=−1`
- 格式:MUSCL-Hancock,`N = 800`,求解器 HLL 与 HLLD
- `Bx = 0.75` 恒定 → 1D 下 `∇·B = 0` 自动满足,**无需 GLM**

### 1.2 保留的数据
```
results/mhd/brio_wu/brio_wu_muscl_{hll,hlld}_{fp64,fp32}_N800.dat   (4 个)
logs/mhd/brio_wu_muscl_{hll,hlld}_{fp64,fp32}_N800.log             (4 个)
```
四个都跑满 **760 步、无崩溃**(fp32 在 1D 完全稳定)。

### 1.3 结果表(正文用):fp32 vs fp64 相对误差 `relL2`(≈ 有效位数)

| 变量 | HLL relL2 | (≈位数) | HLLD relL2 | (≈位数) |
|------|-----------|---------|------------|---------|
| ρ    | 2.2e-07   | ~6.7    | 9.3e-07    | ~6.0    |
| vx   | 1.2e-06   | ~5.9    | 8.2e-06    | ~5.1    |
| vy   | 9.4e-07   | ~6.0    | 6.6e-06    | ~5.2    |
| p    | 3.1e-07   | ~6.5    | 2.3e-06    | ~5.6    |
| By   | 2.3e-07   | ~6.6    | 1.5e-06    | ~5.8    |
| E    | 2.4e-07   | ~6.6    | 1.4e-06    | ~5.9    |

*(vz、Bz、Bx 恒为 0 — 1D 平面问题,Bx 常数)*
**完整四范数(L1/L2/L∞/relL2)见 [附录 A](#附录-a完整误差范数表)。**

误差高度集中在间断处:以 HLLD 的 vx 为例,`L1=5.9e-7` 而 `L∞=5.4e-5`(**L∞/L1 ≈ 90**),
说明光滑区吻合到 ~7 位,误差几乎全在激波 / 接触 / compound wave 上。

### 1.4 结论
1. **fp32 在 1D Brio-Wu 完全够用**:两个求解器都保 ~5–6 位有效数字,不崩。温和问题下单精度无压力。
2. **HLL 比 HLLD 对精度更不敏感**(relL2 小 ~4–10×)。HLLD 运算多、分支多 → 舍入分歧更大。
   这是"求解器越复杂 → fp 敏感度越高"的**确定性佐证**(严格版留给 MCA)。
3. **误差集中在间断**(L∞ ≫ L1)—— 光滑区 fp32 绰绰有余,是尖锐结构吃精度。
4. 速度分量(vx, vy)误差最大 —— 含除法 `ρu/ρ`,且 compound wave 处速度梯度陡。
